# User experience and reviews: chat, writing, code, no-code app builders, agents (categories 1, 2, 10, 11, 12)

All pages read on 2026-11-18. **READ** = seen on the fetched page. **INFERRED** = from a search-result title or snippet only. **Assumption** = not verified. **STALE** = older than 6 months (before mid-May 2026). Reddit was not used. Fetch budget: 25 used (2 failed: tech-insider.org and thenewstack.io). The HN Algolia API was blocked by the proxy, so HN threads were found through site-limited search.

**How to read Trustpilot here.** Almost every AI profile below is unclaimed, and the company does not invite reviews. That draws mostly angry customers, so on those profiles 75 to 95% of reviews are 1-star. Read these profiles as **evidence about billing, support and limits**, not as an overall quality score. The exceptions are QuillBot, Make and Base44, which do reply to or collect reviews, and their scores are higher. **Do not compare a Trustpilot score with a G2 score.** The previous report already notes that G2 gives these tools high scores (for example Claude Code NPS 90 on G2, Manus 2.4 on G2); see `/home/user/ai-atlas/research/community/all-categories-report.md`.

## Q1. Review-platform scores and repeated praise and complaint themes, per tool

### Takeaway
Across all five categories, users praise the output and complain about the business around it. The same four complaints repeat on every profile: (1) credits or usage limits run out faster than expected, (2) refunds are refused and auto-renewals catch people out, (3) support is an AI bot with no human escalation, and (4) the AI says it made a change when it did not. QuillBot is the only tool in scope with a high, large-sample Trustpilot score (4.8 from about 14.8K reviews).

### Inferences
- In every category, one Trustpilot complaint pattern stands out: **credit-based pricing in which failed AI output still costs credits** (Bolt, Base44, Manus, Figma Make, Gamma, Cursor, Copilot). For design students, "how fast credits run out" is the most important practical warning on a tool card.

- A refund policy is a trust signal worth showing. "No refunds" or very short refund windows are reported for Gamma (3 days), Cursor, Zapier, Manus, Bolt and Base44 (annual plans).

## Q3. First-person long-term experience and Hacker News: what heavy users conclude

### Takeaway
Heavy users in 2026 conclude that **the model matters less than the harness, the visibility and the price structure**. On HN, Cursor keeps a loyal group of users for its GUI diff review and tab completion, but many have moved to Claude Code or Codex for cost and agent quality. Long-term Claude Cowork users say scheduled automation works once you invest in maintaining it. Automation implementers move cost-sensitive teams off Zapier.

### Cited Findings
- **HN, "Is anyone on HN still actually using Cursor in 2026?"** (about July 2026; comments show "4 months ago"; parent story "SpaceX to buy Cursor for $60B"). By an approximate tally, about 20 replies still use Cursor and about 8 have moved (to VS Code with Claude Code or Codex, Zed, or Codex CLI). Many use both. Representative comments:
  - "Composer 2.5 is a beast. But even with Opus... their harness is many times faster" (eranation).
  - "I really just prefer the GUI of having the changes easily highlighted" (jjice).
  - "Claude Code hides too much of what it's doing from me" (x3n0ph3n3).
  - "I stopped using Cursor because of how terribly optimised it is", meaning CPU and RAM use; this user moved to Zed (joefourier).
  - Some say the SpaceX deal makes them consider leaving.

### Inferences
- For design students, the HN remark "I prefer the GUI of having the changes easily highlighted" is the useful point: visible diffs (Cursor, Copilot in VS Code) suit beginners and visual thinkers, while terminal agents (Claude Code, Codex) suit people who are comfortable not seeing every step.
- "Start small, then expand" recurs in the long-term posts (Cowork, n8n migrations). Agents reward patience and maintenance, not one-shot use.

### Gaps
- No long-term first-person posts were read for Gemini, Perplexity, Gamma, Canva, Lovable, Replit, v0, Codex or Claude Code in this round.
- No YouTube titles or view counts were gathered.

## Q4. Per category: which tool users say they switched TO and AWAY from in 2026, and why

## Q5. Per category: which free plan users call usable, and which paid plan they call good value

### Takeaway
Users rarely call any free plan "enough". The positive mentions found:
- **Make's free tier**: "more generous than n8n".
- **Self-hosted n8n**: effectively free (about £8/month for a server), but only for technical users.
- **DeepSeek**: "completely free".
- **ChatGPT's free plan**: more generous than Claude's.

Good value is claimed for Claude Pro (€22, "reasonable") and for Claude Code and Cursor grandfathered subscriptions against metered alternatives. Credit-metered tools (Gamma, Bolt, Base44, Figma Make, Manus, Copilot after June 2026) are repeatedly called poor value because failed output still costs credits.

### Cited Findings
- **Chat:** "ChatGPT's free plan is more generous" than Claude's 5-hour window (STALE, [Built In](https://builtin.com/articles/chatgpt-claude-switching-analysis)). Perplexity paid users say they run out of credits mid-task ([Trustpilot Perplexity](https://www.trustpilot.com/review/perplexity.ai?page=1)).
